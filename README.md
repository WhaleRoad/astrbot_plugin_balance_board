# 余额面板 astrbot_plugin_balance_board

先认模型，再问钱。

AstrBot 挂了哪几家服务商、各剩多少钱，做成一块面板。接口地址从 AstrBot 的 provider 配置里读，
key 直接复用已经配好的那把，插件里不用再填一遍。认厂商靠 api_base 的域名，DeepSeek / 硅基流动 / Kimi
三家走官方余额接口；本地模型、自建站这种没有余额接口的，老老实实标一句「这家没接口」。

## 装法

丢进 `data/plugins/` 就行，目录名保持 `astrbot_plugin_balance_board`，重启 AstrBot。
依赖只有 aiohttp（AstrBot 自带）。

## 用起来

- `/余额` 看当前会话挂的这家还剩多少，顺带报一下比上次少了多少
- `/余额 全部` 把所有挂着的服务商列一遍

WebUI 里打开「余额面板」那个页，分两个 tab：

**用量** —— 充值余额、累计消费、按时间维度和服务商筛的柱状图，下面是查询明细。
首页大字是估算值，靠余额差算的，跟平台真实账单对不上是正常的，别当发票用。

**设置** —— 手动查一家（自建站 / 中转站填地址和 key）、挂着的服务商一览、提醒设置、刷新间隔。
改完保存立刻生效，不用重启。

## 配置

| 项 | 默认 | 干什么 |
| --- | --- | --- |
| `refresh_minutes` | 10 | 隔多久拉一次余额，1–720 分钟 |
| `low_balance` | 2.0 | 低于这个数提醒一句，填 0 不提醒。按账户自己的币种比，不换算 |
| `alert_cooldown_hours` | 0 | 0 是只提醒一次，充值回到线上才复位 |
| `notify_session` | 空 | 提醒发到哪个会话，格式 `平台:消息类型:会话号`，留空发最后一次说话的会话 |
| `default_platform` | 空 | 只填会话号时补的平台名，比如 napcat |
| `show_unsupported` | 开 | 没接口的服务商也列出来 |
| `bot_name_prefixes` | 空 | 生成提醒时剥掉的名字前缀，逗号分隔 |
| `allow_open_browser` | 开 | 点「去充值」由后端唤起本机浏览器打开官方充值页 |

## 提醒

余额掉到 `low_balance` 以下推一条，交给当前人设用自己的话说，不套模板。
只在跌破那一刻说一次，充值回到线以上才复位，不会一直嚷嚷。

## 数据

状态存在 `data/plugin_data/astrbot_plugin_balance_board/state.json`，只留最近 500 条余额记录。
key 不落盘，每次运行时从 AstrBot 配置里读。

## 已知限制

- 消费金额是余额差估出来的，插件拿不到平台账单，七位数以内的小额误差是常态
- 没余额接口的服务商只能显示「没接口」，按 token 记账那条腿还没做
